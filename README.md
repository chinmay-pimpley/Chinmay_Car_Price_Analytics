# Used Car Price Analytics & Machine Learning

## Project Overview
This project performs end-to-end data analytics and machine learning on ~558,000 used-vehicle auction/sale transactions to analyze pricing patterns and build a predictive model for used-car selling prices.

---

## Business Problem
> **"Analyzing used vehicle sales patterns and predicting the selling price of used vehicles."**

Key questions answered:
- What factors are associated with used-car selling prices?
- How do vehicle age and mileage relate to selling price?
- Which manufacturers have different price patterns?
- How does vehicle condition relate to selling price?
- How does MMR relate to actual selling price?
- Can machine learning predict a vehicle's selling price?
- Which factors contribute most to predicted price?
- How can the analysis support pricing and valuation decisions?

---

## Objectives
1. Clean and prepare used-car sales data
2. Analyze important factors associated with vehicle selling prices
3. Identify meaningful patterns across makes, models, body types, transmission types
4. Statistically test selected relationships
5. Build a machine-learning regression model for selling-price prediction
6. Evaluate model performance using MAE, RMSE, R²
7. Present findings through an interactive Node.js dashboard
8. Provide evidence-based business recommendations

## Data Cleaning Summary

| Step | Action |
|---|---|
| Missing `sellingprice` | Dropped (cannot train without target) |
| Missing `saledate` | Dropped (needed for feature engineering) |
| `sellingprice` < $100 | Dropped (data-entry errors) |
| `year` outside 1980–2016 | Dropped (invalid) |
| `odometer` > 500,000 | Dropped (data-entry errors) |
| Invalid `transmission` values (`'sedan'`) | Set to NaN → filled as Unknown |
| Missing categoricals | Filled with 'Unknown' |
| Missing `odometer` | Imputed with median |
| Missing `condition` | Imputed with median |
| Missing `mmr` | Imputed with median |
| Garbled `interior` characters | Set to NaN → filled as Unknown |

## 5 Observations

1. Selling price distribution is right-skewed — mean exceeds median due to high-value vehicles.
2. Vehicle age has a negative correlation with selling price; depreciation is consistent.
3. Odometer reading has a negative Pearson correlation with selling price.
4. Among the top 10 makes, significant price differences exist between manufacturers.
5. MMR has a very strong positive Pearson correlation with actual selling price.

*All values calculated from actual data — see notebook outputs.*

---

## 5 Insights

1. **Skewed distribution:** Pricing strategies should use the median, not the mean, to represent typical market transactions.
2. **Depreciation:** 1–3 year old vehicles are the sweet spot — capturing depreciation benefit while maintaining high resale values.
3. **Mileage:** Moderate negative predictor — brand and condition also matter significantly.
4. **Brand premium:** Persists in the used-car market; brand should factor into reserve price setting.
5. **MMR utility:** Highly predictive; MMR-integrated pricing tools provide substantially better accuracy.

## ML Methodology

### Problem Type
Regression — predict `sellingprice` (continuous USD value)

### Configurable Model Selection


### Models Available
| Model | Notes |
|---|---|
| Linear Regression | Baseline linear model |
| Ridge Regression | Regularized linear model |
| Random Forest Regressor | Ensemble tree method (default) |
| Gradient Boosting Regressor | Boosted tree method |

### Train/Test Split
80% train / 20% test — random split (general prediction goal, not time-series)

### Preprocessing Pipeline
- **Numerical:** median imputation → StandardScaler
- **Categorical:** constant imputation ('Unknown') → OneHotEncoder (handle_unknown='ignore')
- Implemented via sklearn `Pipeline` + `ColumnTransformer`

## MMR Leakage Decision

MMR (Manheim Market Report) is a **pre-sale** independent market valuation — available before the auction occurs. It is **not leakage**. Including it in Model A simulates a realistic dealer/auctioneer scenario.

Features derived from `sellingprice` (e.g., `sellingprice - mmr`) are **excluded** from all models.

---

## 3 Business Recommendations

1. **MMR-Assisted Pricing Workflow** — Integrate Manheim Market Report into pre-sale pricing tools; list within ±5% of MMR for optimal competitive positioning.
2. **Age & Mileage-Based Inventory Sourcing** — Prioritise 1–3 year old, low-mileage vehicles to capture the optimal depreciation/resale value trade-off.
3. **Model-Supported Reserve Price Setting** — Use the ML model to set auction reserve prices at predicted price × 0.95 to prevent under-selling.
